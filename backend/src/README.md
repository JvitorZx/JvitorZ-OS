# Backend Modular Architecture

Este diretório organiza a base do backend em uma arquitetura modular preparada para escalabilidade.

## Estrutura

- `core/` - componentes centrais do aplicativo
- `modules/` - módulos de domínio principais do sistema
- `operators/` - operadores especializados para integrações e processos
- `shared/` - utilitários e tipos compartilhados entre módulos
