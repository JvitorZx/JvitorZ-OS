# Core

O diretório `core` contém a infraestrutura central do backend.

## Responsabilidades

- `config/`: configuração de ambiente e carregamento de variáveis
- `logger/`: sistema de logs para trazabilidade e depuração
- `errors/`: definições de erros personalizados e classes de exceção
- `interfaces/`: contratos e abstrações compartilhadas entre componentes
