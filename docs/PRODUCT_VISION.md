# JvitorZ OS

## Visão
O JvitorZ OS é uma plataforma operacional para criadores de conteúdo. Seu objetivo é centralizar planejamento, produção, análise e automação em um único ambiente inteligente. A Dashboard fornece uma visão geral do ecossistema, enquanto os operadores são os espaços de trabalho especializados onde as tarefas realmente acontecem. Cada operador resolve um problema específico, compartilha componentes reutilizáveis e integra-se aos demais, formando um sistema coeso, escalável e preparado para evoluir continuamente.

## Missão
Ser o núcleo operacional de criadores de conteúdo, conectando planejamento, execução e análise em um único sistema que facilite decisões e otimize fluxos de trabalho.

## Filosofia
- Dashboard é apenas a Home do sistema.
- O trabalho acontece dentro dos Operadores.
- Cada Operador resolve um problema específico.
- Componentes devem ser reutilizáveis.
- A experiência do usuário vem antes de novas funcionalidades.
- Nenhuma funcionalidade existe sem um objetivo claro.

## Princípios de UX
- Sidebar sempre fixa.
- Dashboard apenas para monitoramento.
- Operadores ocupam a Workspace completa.
- Biblioteca única para todo o sistema.
- Histórico individual por operador.
- Prompt Base pertence às configurações do operador.
- Navegação sem botão "Voltar"; a Sidebar é o meio oficial de navegação.

## Objetivos de longo prazo
- Centralizar todo o fluxo de criação de conteúdo.
- Integrar IA em todos os operadores.
- Automatizar tarefas repetitivas.
- Transformar o JvitorZ OS em uma plataforma operacional para criadores de conteúdo.
